# SPRINT - Dashboard Monitoring Agunan & APM Emas 🚀

Ini adalah mockup UI/UX untuk sistem **SPRINT PT Pegadaian (Persero)** yang mencakup Collateral Security System (CSS), pemantauan Agunan, Inventory Tracker, Menu Laporan, dan integrasi log mesin APM Emas.

## 🌟 Fitur dan Flow Halaman (Mockup)
Mockup ini memiliki beberapa *view* yang interaktif dan dapat diuji coba secara langsung:
1. **Dashboard Utama**: Menampilkan summary statistik, menu E-Form, Utilitas, dan notifikasi alert.
2. **Dashboard Monitoring**: Memantau pergerakan Barang Jaminan (BJ) secara realtime, termasuk *Warning Alert* (< 12 Jam) dan *High Alert* (> 12 Jam).
3. **Inventory Tracker**: Tabel pemantauan data inventory lengkap dengan fitur filter tanggal, kantor wilayah, cabang, dan nama produk.
4. **Menu Laporan**: Menampilkan log data barang jaminan dan log akses kluis untuk diaudit, beserta tombol simulasi export (Excel/PDF).
5. **Dashboard APM Emas (Gadai Otomatis)**: Modul khusus untuk memantau status kapasitas mesin APM Emas dan detail transaksinya.
6. **Handheld CSS Module (Mobile View)**: Simulasi penggunaan *scanner handheld* untuk proses *Pairing* (Scan QR & RFID) dan *Unpairing* secara *on-site*.

## 🛠️ Teknologi yang Digunakan
*   **HTML5**
*   **Tailwind CSS** (via CDN)
*   **Vanilla JavaScript** (untuk navigasi *tab*, kalkulasi konter, filter tabel, dan interaksi *modal* popup)
*   **FontAwesome 6** (untuk ikonometri)
*   **Google Fonts** (Plus Jakarta Sans)

## 🚀 Cara Menjalankan Secara Lokal
Tidak perlu proses instalasi (Node.js/NPM). Cukup unduh file HTML ini dan buka langsung di *browser* pilihan Anda:
1. *Clone repository* ini: `git clone <url-repo-anda>`
2. Buka file `index.html` menggunakan Google Chrome, Mozilla Firefox, atau Safari.
